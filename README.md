# Transmisión

Transmisión es una app de pantalla compartida de baja latencia para Windows. Permite compartir tu pantalla y tu audio con amigos usando un código de sala.

## Requisitos

- Windows 10/11 de 64 bits
- Tarjeta gráfica NVIDIA (para el vídeo)

## Descargar

[Descargar la última versión](https://github.com/Frantejeda1993/transmision-releases/releases/latest)

## Instalación

1. Descarga el instalador (`.exe`) desde el enlace anterior.
2. Ejecútalo. Si Windows SmartScreen muestra un aviso ("Windows protegió su PC"), pulsa "Más información" y luego "Ejecutar de todas formas": la app no está firmada digitalmente.
3. Abre Transmisión desde el menú Inicio y comparte o únete con un código de sala.

## Aviso

Es un proyecto personal compartido con amigos, ofrecido tal cual, sin garantías.
